C++ does not execute line-by-line at runtime like Python. It undergoes a multi-stage compilation process to build a standalone executable file (`.exe` or binary).

## The 4 Stages of Compilation
### Step 1: Preprocessing
The preprocessor scans the source code (`.cpp`) for lines starting with `#` (directives).
* Expands `#include` statements by copy-pasting the header content directly into the file.
* Replaces `#define` macros with their actual values.
* *Output:* A pure, expanded source code file.

### Step 2: Compilation
The compiler takes the preprocessed code and translates it into **Assembly language** specific to the computer's CPU architecture.
* *Output:* Assembly code file (`.s` or `.asm`).

### Step 3: Assembly
The assembler takes the assembly code and translates it into raw binary machine code (1s and 0s).
* *Output:* An **Object File** (`.obj` on Windows, `.o` on Mac/Linux). This code is not yet runnable because it lacks standard library connections.

### Step 4: Linking
The **Linker** merges all your separate object files together with the pre-compiled code of the C++ Standard Library (like `std::cout`).
* *Output:* The final executable program (`main.exe` or `a.out`).
