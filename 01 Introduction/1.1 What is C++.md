## Overview
C++ is a high-level, general-purpose, compiled programming language created as an extension of the C programming language. It is known for its efficiency, performance, and precise control over system resources like memory.

## Core Characteristics
### 1. Mid-Level Language
C++ bridges the gap between high-level language (like python or Java) and low-level machine code. It allows for direct hardware manipulation while maintaining abstract coding paradigms.

### 2. Multi-Paradigm
Unlike languages that force you into a single programming style, C++ supports:
* **Procedural Programming:** Structured coding using functions and blocks (inherited from C).
* **Object-Oriented Programming (OOP):** Organizing code around real-world objects using classes, encapsulation, inheritance, and polymorphism.
* **Generic Programming:** Writing reusable code independent of data types using *Templates*.

### 3. Manual Memory Management
C++ does not rely on an automatic Garbage Collector. Developers explicitly allocate and deallocate memory using `new` and `delete` (or modern smart pointers), offering unparalleled runtime performance.

> [!NOTE]
> **Key Takeaway:** If Python is an automatic car that is easy to drive but restricts control, C++ is a manual sports car. It requires deep knowledge to handle safely, but it is incredibly fast and powerful.
