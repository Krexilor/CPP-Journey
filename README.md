## C++ Learning Journey
Welcome to my C++ learning repository.

This repository serves as a personal learning log and knowledge base documenting my journey from beginner to advanced C++ development. The goal is simple: learn C++ deeply, build projects, understand core programming concepts, and eventually master the language.

## What You'll Find Here
* Structured notes written in **Obsidian**.
* C++ concepts and explanations
* Code examples and experiments
* Problem-solving approaches
* Project development notes

## Goals
* Build a strong foundation in modern C++
* Understanding memory management and pointers
* Master Object-Oriented Programming (OOP)
* Learn Data Structures and Algorithms using C++
* Explore STL (Standard Template Library)
* Write Clean, efficient, and maintainable code
* Build real-world projects
* Reach an advanced level of C++ proficiency

## Progress Philosophy
This repository is not a polished tutorial.

It is a record of learning, mistakes, discoveries, experiments, and improvements, Notes may evolve, be rewritten, or become more detailed as my understanding grows.
