## Overview
A **multi-dimensional array** is an arrays - most commonly used a **2D array** to represent grids, matrices, tables, or game boards. C++ supports arrays of any dimension, though 2D and occasionally 3D are what you'll encounter in practice.

## Declaring & Initializing a 2D Array
```cpp
// Syntax: type name[rows][columns];
int grid[3][4];

// Declaration + initialization
int matrix[2][3] = {
	{1, 2, 3},
	{4, 5, 6}
};

// Flat initialization (less radable, same result)
int matrix[2][3] = {1, 2, 3, 4, 5, 6};
```

>[!NOTE]
>Conceptually, a 2D array is a grid - `matrix[row][col]`. Internally, C++ still stores it as one continuous, contiguous block or memory (covered in detail in the next file or Array Memory Layout).

## Accessing 2D Array Elements

```cpp
int matrix[2][3] = {
	{1, 2, 3},
	{4, 5, 6}
};

cout << matrix[0][0] << endl;     // 1 (row 0, col 0)
cout << matrix[1][2] << endl;     // 6 (row 1, col 2)

matrix[0][1] = 100;               // modify row 0, col 1
cout << matrix[0][1] << endl;     // 100
```

>[!WARNING]
>Just like  1D arrays, there is **no bounds checking**. Accessing `matrix[5][10]` on a `[2][3]` array is undefined behavior, not a clean error.

## Iterating a 2D Array
Requires **nested loops** - the outer loop walks rows, the inner loop walks columns.

```cpp
int matrix[2][3] = {
	{1, 2, 3},
	{4, 5, 6}
};

for (int row = 0; row < 2; row++) {
	for (int col = 0; col < 3; col++) {
		cout << matrix[row][col] << " ";
	}
	cout << endl;
}

/*
Output:
1 2 3
4 5 6
*/
```

## Common 2D Array Operations

### Sum of All Elements

```cpp
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
int total = 0;

for (int row = 0; row < 2; row++) {
	for (int col = 0; col < 3; col++) {
		total += matrix[row][col];
	}
}
cout << "Total: " << total << endl;     // 21
```

### Row Sums and Column Sums

```cpp
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};

// Sum of each row
for (int row = 0; row < 2; row++) {
	int rowSum = 0;
	for (int col = 0; col < 3; col++) {
		rowSum += matrix[row][col];
	}
	cout << "Row " << row << " sum: " << rowSum << endl;
}

// Sum of each column
for (int col = 0; col < 3; col++) {
	int colSum = 0;
	for (int row = 0; row < 3; row++) {
		colSum += matrix[row][col];
	}
	cout << "Col " << col << " sum: " << colSum << endl;
}
```

### Matrix Transpose
Swapping rows and columns - `matrix[row][col]` becomes `result[col][row]`.

```cpp
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
int trasponsed[3][2];     // dimensions flipped

for (int row = 0; row < 2; row++) {
	for (int col = 0; col < 3; col++) {
		transposed[col][row] = matrix[row][col];
	}
}

/*
Output:
1 4
2 5
3 6
*/
```

### Matrix Addition
Two matrices of identical dimensions, added element-wise.

```cpp
int a[2][2] = {{1, 2}, {3, 4}};
int b[2][2] = {{5, 6}, {7, 8}};
int result[2][2];

for (int row = 0; row < 2; row++) {
	for (int col = 0; col < 2; col++) {
		result[row][col] = a[row][col] + b[row][col];
	}
}

/*
Output:
6 8
10 12
*/
```

### Three-Dimensional Arrays
For completeness - a 3D array adds a third index, often visualized as "stack of grids."

```cpp
int cube[2][2][2] = {
	{ {1, 2}, {3, 4} },
	{ {5, 6}, {7, 8} }
};

cout << cube[1][0][1] << endl;     // 6

for (int x = 0; x < 2; x++) {
	for (int y = 0; y < 2; y++) {
		for (int z = 0; z < 2; z++) {
			cout << cube[x][y][z] << " ";
		}
	}
}
```

>[!TIP]
>Beyond 2D, multi-dimensional arrays become rare in everyday code - 3D+ structures are typically modeled with `std::vector<std::vector<std::vector<T>>>` or flattened 1D arrays with manual index math, both of which offer better flexibility than raw nested arrays.
