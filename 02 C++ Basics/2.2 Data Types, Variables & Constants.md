## Overview
A **variable** is a named storage location in memory that holds a value. Every variable in C++ must have a **type** declared at the moment of creation. The type tells the compiler how much memory to allocate and how to interpret the stored bits.

## Fundamental Data Types
| Type        | Description              | Size (typical) | Example Value    |
| ----------- | ------------------------ | -------------- | ---------------- |
| `int`       | Whole numbers            | 4 bytes        | `42`, `-7`       |
| `double`    | Floating-point (decimal) | 8 bytes        | `3.14`, `-0.001` |
| `float`     | Single-precision decimal | 4 bytes        | `3.14f`          |
| `char`      | Single character         | 1 byte         | `'A'`, `'false'` |
| `bool`      | True or False            | 1 byte         | `true`, `false`  |
| `string`    | Sequence of characters   | Dynamic        | `"Hello"`        |
| `long long` | Large while numbers      | 8 bytes        | `987654321`      |

> [!NOTE]
>  Unlike the others, `string` is a class from the Standard Library (`#include <string>`). It is included automatically with `<iostream>` in most compilers, but it's good practice to include it explicitly.

## Type Modifiers
Modifiers adjust the range and storage of base types.

| Modifier        | Effect                                              |
| --------------- | --------------------------------------------------- |
| `unsigned int`  | No negative values. Range doubles on positive side. |
| `short int`     | 2 byte instead of 4.                                |
| `long int`      | At least 4 bytes (often same as int on 64-bit).     |
| `long long int` | Guaranteed 8 bytes.                                 |

```cpp
`unsigned int score = 4294967295;      // Max value, no negatives`
`short int temp = -32000;`
`long long int bigNumber = 9000000000LL;`
```

## Declaring & Initializing Variables
```cpp
// Declaration (memory reserved, value is garbase/undefined)
int age;

// Initialization (declaration + value assignment)
int age = 25;

// Modern C++11 uniform initialization (preferred)
int age{ 25 };
double price{ 9.99 };
string name { "Krexilor" };
```

> [!WARNING]
> **Uninitialized Variables:** Reading an uninitialized variable is **undefined behavior** in C++. It may contain random garbage data from whatever was previously at the memory address. Always initialize your variables.

## `auto` Keyword (C++11)
The `auto` keyword let the compiler **deduce the type** from the assigned value. Usefule when the type is obvious or complex.

```cpp
auto score = 100;                      // deduced as int
auto price = 19.99;                    // deduced as double
auto name = "Krex";                    // deduced as const char* (not string!)

auto name = string{"Krex"};            // explicitly a string
```

> [!NOTE]
> **When to use auto:** Use `auto` when the type is either obvious from context or very verbose (like iterator types). Avoid it when it obscures what type a variable actually is.

## Constants
A **constant** is a variable whose value cannot be changed after initialization.

### `const` - Runtime Constants
```cpp
const double PI = 3.14159265;
const int MAX_PLAYERS = 4;

PI = 3.0            // ERROR: cannot modify a const variable
```

### `constexpr` - Compile-Time Constant (C++11)
`constexpr` forces evaluation at **compile time**, making it faster than `const` for values that are truly fixed.

```cpp
constexpr int SCREEN_WIDTH = 1920;
constexpr double GRAVITY = 9.81;
```

> [!NOTE]
> **const vs constexpr:** Use `constexpr` for values known at compiler time (screen sizes, math constants, fixed limits). Use `const` for values that are fixed at runtime but not necessarily known during compilation (e.g., a user's input stored as a constant).

## Naming Convention
```cpp
int playerHealth;                      // camelCase (common for variables)
const int MAX_HEALTH;                  // UPPER_SNAKE_CASE (common for constants)
string firstName;                      // camelCase
```

Rules enforced by the compiler:
* Must start with a letter or underscore `_`.
* Cannot be a C++ keyword (`int`, `return`, `class`, etc.).
* Case-sensitive (`Score`  ≠ `score`)
