## Overview
Every C++ program follows a strict structural contrast. Before diving into syntax rules, it's crucial to understand *what is each part of a program is*, *why it exists*, and *what happens if you remove it*.

## Anatomy of a C++ Program
```cpp
#include <iostream>
using namespace std;

int main() {
	cout << "Hello, World!" << endl;
	return 0;
}
```

### `#include <iostream>`
This is a **preprocessor directive**. It instructs the preprocessor to copy the entire contents of the `iostream` header file into your source file before compilation begins. `iostream` provides the tools for **inputs** (`cin`) and **output** (`cout`).

> [!NOTE]
> **Key Takeaway:** C++ does not know what `cout` is by default. All standard functionality lives in separate header files. You must explicitly *include* what you need - this is intentional design for performance and compile-time control.

### `using namespace std;`
The C++ standard Library wraps all its features inside a **namespace** called `std` to avoid name conflicts. Without this line, you would have to write `std::cout` and `std::endl` everywhere.

> [!WARNING]
> `using namespace std;` is convenient for learning but is considered bad practice in large or production codebase. It pollutes the global namespace and can cause ambiguous name conflicts. Prefer `std::cout` explicitly in real projects.

### `int main( )`
This is the **entry point** of every C++ program. The OS calls `main( )` when the program launches. The `int` return type signals an exit code back to the operating system.
* `return 0;` → Program finished successfully.
* Any non-zero value → Signals an error to the OS.

> [!NOTE]
> **Key Takeaway:** `main( )` is not just a function - it is the mandatory contract between the program and the operating system. Every C++ program must have exactly one `main ( )`.

### `cout << "Hello, World! " << endl;`
* `cout` → Character Output stream. Sends data to the console.
* `<<` → The **stream insertion operator**. Think of it as "push this into the stream".
* `endl` → Ends the line and **flushes** the output buffer. Equivalent to `"\n"` but slightly slower due to the flush.

## Statements & Semicolons
Every **statement** in C++ must end with a semicolon `;`. A statement is a single instruction for the computer to execute.

```cpp
cout << "Line one." << endl;           // Statement 1
cout << "Line two." << endl;           // Statement 2
```

> [!WARNING]
> **Missing Semicolon:** Forgetting a `;` is one of the most common beginner errors. The compiler error will often point to the *next* line, not the line missing the semicolon - don't be misled.

## Comments
Comments are ignored by the compiler and exist solely for the developer.
```cpp
// This is a single-line comment

/* 
	This is a
	multi-line comment
*/
```
