## Overview
By default, C++ executes code line by line, from top to bottom. **Control flow** statements break that linear path - they let you make decisions, repeat actions, and jump between branches based on conditions.

---
## Control Statements
### 1. `if` / `else if` / `else`
The most fundamental decision-making construct.

```cpp
int score = 78;

if (score >= 90) {
	cout << "Grad: A" << endl;
} else if (score >= 80) {
	cout << "Grade: B" << endl;
} else if (score >= 70) {
	cout << "Grade: C" << endl;
} else {
	cout << "Grade: F" << endl;
}

// Output: Grade: C
```

> [!NOTE]
> Even if the body is a single statement, always use `{ }`. Omitting them is legal but leads to subtle bugs when you add a second line later and forget that only the first is inside the `if`.

### 2. `switch` Statement
An efficient alternative to long `if/else if` chains when comparing a **single integer or character** against multiple fixed values.

```cpp
int day = 3;

switch (day) {
	case 1:
		cout << "Monday" << endl;
		break;
	case 2:
		cout << "Tuesday" << endl;
		break;
	case 3:
		cout << "Wednesday" << endl;
		break;
	default:
		cout << "Other day" << endl;
		break;
}

// Output: Wednesday
```

> [!WARNING]
> Without `break`, execution **falls through** to the next case and runs it too. This is sometimes intentional (e.g., grouping cases), but is most often a bug.

```cpp
// Intentional fall-through: grup cases
switch (day) {
	case 6:
	case 7:
		cout << "Weekend!" << endl;
		break;
	default:
		cout << "Weekday." << endl;
}
```

> [!NOTE]
> Use `switch` when you have 3+ branches comparing the same variable against fixed constant values. It is typically compiled into a **jump table**, making it faster than a chain `if/else if`.

## Loops
### 1. `for` Loop
Use when you know **exactly how many times** you want to repeat.

```cpp
// Syntax: for (initialization; condition; update)
for (int i = 0; i < 5; i++) {
	cout << "Iteration: " << i << endl;
}

// Output: Interation: 0, 1, 2, 3, 4
```

#### Range-Base `for` Loop (C++11)
A cleaner syntax for iterating over collections.

```cpp
int scores[] = {85, 92, 78, 90};

for (int score : scores) {
	cout << score << " ";
}

// Output: 85 92 78 90

// Use const& to avoid copying large objects
for (const int& score : scores) {
	cout << score << " ";
}
```

### 2. `while` Loop
Use when you want to repeat as long as a condition is true, and the number of iterations is **not known upfront**.

```cpp
int count = 0;

while (count < 5) {
	cout << "Count: " << count << endl;
	count++;
}
```

> [!WARNING]
> If the condition never becomes `false`, the loop runs forever and hangs the program. Always ensure the loop variable is modified inside the body.

### 3. `do-while` Loop
Like a `while` loop, but the body executes **at least once** before the condition is checked.

```cpp
int choice;

do {
	cout << "Enter a number (0 to quit): ";
	cin >> choice;
	cout << "You entered: " << choice << endl;
} while (choice != 0);
```

> [!NOTE]
> Ideal for menu systems and input validation where you always need to run the body once before checking if you should continue.

## Loop Control

### 1. `break` - Exit the loop immediately

```cpp
for (int i = 0; i < 10; i++) {
	if (i == 5) break;
	cout << i << " ";
}

// Output: 0 1 2 3 4
```

### 2. `Continue` - Skip the current iteration

```cpp
for (int i = 0; i < 10; i++) {
	if (i % 2 == 0) continue;             // Skip even numbers
	cout << i << " ";
}

Output: 1 3 5 7 9
```

---
## Nested Loops
A loop inside another loop. The inner loop completes its full cycle for every single iteration of the outer loop.

```cpp
for (int row = 1; row <= 3; row++) {
	for (int col = 1; col <= 3; col++) {
		cout << "(" << row << "," << col << ") ";
	}
	cout << endl;
}

/*Output:
(1, 1) (1, 2) (1, 3)
(2, 1) (2, 2) (2, 3)
(3, 1) (3, 2) (3, 3)
*/
```

> [!WARNING]
> A loop inside a loop is `0(n^2)`. Three nested loops are `0(n^3)`. This grows extremely fast. Always think about whether loops are truly necessary in performance-sensitive code.
