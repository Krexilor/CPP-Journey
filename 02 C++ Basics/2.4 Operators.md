## Overview
Operators are symbols that instruct the compiler to perform specific operations on values (operands). C++ has a rich and powerful set of operators that span arithmetic, logic, comparison, and memory manipulation.

## 1. Arithmetic Operators
Use to perform standard mathematical calculations.

| Operator | Meaning        | Example  | Result |
| -------- | -------------- | -------- | ------ |
| `+`      | Addition       | `5 + 3`  | `8`    |
| `-`      | Subtraction    | `5 - 3`  | `2`    |
| `*`      | Multiplication | `5 * 3`  | `15`   |
| `/`      | Division       | `10 / 3` | `3`    |
| `%`      | Modulo         | `10 % 3` | `1`    |

> [!WARNING]
> **Integer Division:** When both operands are integers, `/` performs **integer division** - the decimal part is truncated, not rounded.
> `10 / 3` → `3`, not `3.33`
> To get a decimal result, at least one operand must be a `double`: `10.0 / 3` → `3.333...`

## 2. Assignment Operators
Used to assign or update values in a variable.

| Operator | Meaning                        | Example  | Equivalent to |
| -------- | ------------------------------ | -------- | ------------- |
| `=`      | Assign value                   | `x - 5`  | `Assign 5`    |
| `+=`     | Add and assign                 | `x += 3` | `x = x + 3`   |
| `-=`     | Subtract and assign            | `x -= 3` | x = x - 3     |
| `*=`     | Multiply and assign            | `x *= 3` | `x = x * 3`   |
| `/=`     | Divide and assign              | `x /= 3` | `x = x / 3`   |
| `%=`     | Modulus (remainder) and assign | `x %= 3` | `x = x % 3`   |

## 3. Increment & Decrement Operators
Shorthand to add or subtract 1 from a variable.

```cpp
int x = 5;

// Prefix: increment / decrement first, then use the value
cout << ++x << endl;                 // Output: 6, x is now 6
cout << --x << endl;                 // Output: 5, x is now 5

// Postfix: use the value first, then increment / decrement
cout << x++ << endl;                 // Output: 5, x becomes 6 after
cout << x-- << endl;                 // Output: 6, x becomes 5
```

> [!NOTE]
> **Prefix vs Postfix:** In isolation (`x++` on its own line), there is no difference. The distinction only matters when the expression is used as part of a larger statement or assignment.

## 4. Comparison (Relational) Operators
Return a `bool` result: `true` or `false`.

| Operator | Meaning                  | Example  | Result  |
| -------- | ------------------------ | -------- | ------- |
| `==`     | Equal to                 | `5 == 5` | `true`  |
| `!=`     | Not equal to             | `5 != 3` | `true`  |
| `>`      | Greater than             | `5 > 3`  | `true`  |
| `<`      | Less than                | `5 < 3`  | `false` |
| `>=`     | Greater than or equal to | `5 >= 3` | `true`  |
| `<=`     | Less than or equal to    | `5 <= 3` | `true`  |

> [!WARNING]
> `=` is **assignment** (sets a value). `==` is **comparison** (checks equality). Writing `if (x = 5)` instead of `if (x == 5)` is a classic and dangerous bug - it assigns 5 to x and always evaluates to `true`.

## 5. Logical Operators
Combine or invert boolean expressions.

| Operator | Meaning     | Example            | Result  |
| -------- | ----------- | ------------------ | ------- |
| `&&`     | Logical AND | `true && false`    | `false` |
| `\|\|`   | Logical OR  | `true  \|\| false` | `true`  |
| `!`      | Logical NOT | `!true`            | `false` |

### Short-Circuit Evaluation
C++ stops evaluating a logical expression as soon as the result is determined.
* `false && anything` → immediately `false`, right side skipped.
* `true || anything` → immediately `true`, right side skipped.

This is useful for safety checks (e.g., check if a pointer is not null before dereferencing it).

## 6. The Ternary Operator
A compact one-line alternative to a simple `if/else`.

```cpp
// Syntax: condition ? value_if_true : value_if_false
int a = 10, b = 20;
int max = (a > b) ? a : b;
cout << "Max: " << max << endl;

string status = (age >= 18) ? "Adult" : "Minor";
```

## 7. Operator Precedence (Key Rules)
Operators follow a strict order of evaluation, similar to BODMAS/PEMDAS in math.

```
Higher precedence (evaluated first):
( )                → Parentheses
++, --             → Prefix increment/decrement
*, /, %            → Multiplication, Division, Modulo
+, -               → Addition, Subtraction
<, >, <=, >=       → Comparison
==, !=             → Equality
&&                 → Logical AND
||                 → Logical OR
=, +=, -=          → Assignment (lowest)
```

> [!NOTE]
> Don't rely on memorized precedence rules for complex expressions. Parentheses make intent explicit, improve readability, and eliminate bugs.
> `result = (a + b) * (c - d);` is always clearer than `result = a + b * c - d;`
